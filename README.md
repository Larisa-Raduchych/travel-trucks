# TravelTrucks

Web application for camper van rental. Users can browse available campers, filter them, view details, and book.

## Features

- Home page with hero banner
- Catalog with filtering (location, form, engine, transmission) and Load More pagination
- Camper details page with image gallery, reviews, and booking form
- Responsive design (desktop)

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- TanStack Query (useInfiniteQuery)
- CSS Modules
- Formik + Yup (forms)
- Swiper (gallery)
- React Icons

## Installation

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
